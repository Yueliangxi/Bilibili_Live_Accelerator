# Bilibili Live Accelerator · B 站直播加速器

保留 B 站原生播放器、登录和弹幕，优先使用本次接口提供的**同画质 FLV**，支持官方 CDN 线路偏好、短暂停顿与掉帧分类记录，以及可选的保守自动恢复。

## 一键安装

### [点击安装 / Install](https://raw.githubusercontent.com/Yueliangxi/Bilibili_Live_Accelerator/main/bilibili-live-accelerator.user.js)

1. 先从[油猴官网](https://www.tampermonkey.net/)为浏览器安装 Tampermonkey。
2. 点击上面的「点击安装」，在油猴打开的确认页点击 **Install / 安装**。
3. 停用旧的 `Bilibili Live: Force HTTP-FLV AVC` 及其他修改直播拉流的脚本，刷新直播间。右下角出现「直播加速」按钮即已加载。

不需要下载整个仓库、复制代码、安装 Node.js 或运行终端命令。把本页或上面的安装链接发给朋友即可；对方不需要你的账号、日志或播放地址。

Chrome / Edge 如果提示脚本不能执行，检查油猴扩展的「允许用户脚本」权限，并允许它在 `live.bilibili.com` 运行，详见[油猴官方说明](https://www.tampermonkey.net/faq.php?locale=zh&q=Q209)。不建议为此关闭浏览器安全防护。

如果点击安装后只看见源代码：先确认油猴已安装启用；也可到油猴管理面板 →「实用工具 / Utilities」→「从 URL 导入 / Import from URL」，粘贴安装链接。网络无法访问 GitHub Raw 时，可下载仓库中的 `.user.js` 文件，再用油猴「从文件导入」。

## 怎么用

- 默认启用「同画质 FLV 优先」，**自动恢复默认关闭**。在 B 站原生画质菜单手动选原画；本脚本不自动升降画质。
- 面板上半部分是**实际播放状态**，下半部分是**偏好**。设了 FLV 或某个 CDN，不代表播放器已经采用；看实际协议、节点和分辨率确认。
- 线路只能选 B 站当前接口给出的有效候选，不硬编码节点，不拼接或伪造签名。换线可能短暂缓冲，不保证无缝。
- 没有同画质 FLV 时保留原生方案；选「B 站默认」跟随其协议。显式线路偏好仍可重排官方候选，完全不干预请关闭优化并刷新。
- 「恢复默认」会关闭优化和自动恢复，回到原生协议与线路偏好；刷新后完全恢复原生播放。旧脚本可以保留，但不要同时开启。

## 停顿记录不再等于自动重连条件

v0.2.0 把观测与恢复拆开，自动恢复关闭或处于恢复保护期时，仍记录可观测的停顿。**显示 0 次不保证完全流畅**，也不代表已经确定网络、解码或主播端的原因。

| 面板项目 | 含义 |
| --- | --- |
| 已观测停顿 | 缓冲等待与疑似冻结的合计；同一次连续停顿只计一次 |
| 缓冲等待 | 播放停滞且缓冲接近耗尽，包含媒体事件确认的短暂等待 |
| 疑似冻结 | 播放时间或视频帧长时间不推进，但不足以归为缺缓冲；不是原因确诊 |
| 掉帧 | 播放器报告的丢帧数与近期掉帧比例，单独显示，不加入停顿次数 |
| 最近事件 | 普通停顿开始/结束、较高掉帧样本和恢复操作，不再只记录自动重连 |

媒体 `waiting` / `stalled` 事件持续约 250 毫秒即可确认一次可观测等待；轮询也检查时间/视频帧停滞。后台、主动暂停和拖动期间不新计停顿；切换、刷新、定时器被浏览器限速、指标不可用等仍可能让观测不完整。原始掉帧计数可能随播放器换流而归零。近期事件仅保存在当前页面内存，刷新会重置。

自动恢复仍是另一套保守判断：仅前台、直播、非暂停/非时移、持续缺缓冲至少 8 秒、有同画质有效备线时尝试原生重连；有 15 秒观察保护、90 秒冷却，10 分钟最多 2 次。失败或实际节点未采用时停止本页自动恢复，不因短顿或掉帧频繁重连。

## 更新、反馈与隐私

通过此安装链接安装后，油猴会按自身设置从本仓库检查版本并下载更新；不是秒级推送。脚本的 `@namespace` 保持不变，已有 v0.1.0 用户可从同一链接更新，而不是同时安装两个版本。早期本地安装版没有更新地址，需要手动点此链接更新一次。

问题请到 [Issues](https://github.com/Yueliangxi/Bilibili_Live_Accelerator/issues) 反馈，并注明浏览器、脚本版本、是否暂停/后台、是否转圈及大概持续时间。可点击「复制诊断报告」取得脱敏信息，**不要上传播放器完整日志、Cookie、账号资料或带签名的完整播放 URL**。

脚本无广告、无远程运行依赖，不主动并行拉多路直播测速，不上传诊断；只在本地保存开关、协议及主机名偏好。油猴会正常向 GitHub 请求脚本版本/更新文件，这不包含直播诊断数据。

## 限制与兼容性

目前主要在 Chrome + Tampermonkey 上验证，其他浏览器尚未全面测试。FLV 不一定总比 HLS 快，不同运营商、地区、房间和时段的效果不同。脚本不是代理或 VPN，无法增加总带宽，也无法保证修复主播端断流、解码/渲染掉帧或权限限制；不绕过付费、DRM、版权或登录限制。

B 站网页和原生播放器接口可能变化；识别不到兼容原生入口时，自动恢复不可用。部分浏览器不支持视频帧回调时，仅使用可用的播放时间、缓冲和媒体事件，不能保证检测所有肉眼可见的冻结。

## 开发

需要 Node.js 18 或更新版本，无第三方运行依赖。

```sh
npm test
npm run build
npm run check
```

源码：`src/core.js`（线路、独立观测与恢复判断）、`src/runtime.js`（网页接入）、`src/panel.js`（隔离面板）。构建生成完整的 `bilibili-live-accelerator.user.js` 和只含版本元数据的 `bilibili-live-accelerator.meta.js`。

```sh
node scripts/preview.js
```

打开 `http://127.0.0.1:42371/` 可检查模拟界面，不连接 B 站、不代表真实播放测试。发布时提高 `package.json` 的版本号，运行构建与测试，提交两个生成文件及相关源码，再推送到 `main`，以免更新元数据与代码不一致。
